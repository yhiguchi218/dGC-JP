# Data Sources

| Dataset | Primary source | Validation method | Redistribution status |
| --- | --- | --- | --- |
| Height/Weight LMS | Isojima et al. (2016), based on the 2000 MHLW national survey | Spot-checked against the published LMS tables and covered by automated interpolation/clinical validation tests | Numeric reference values are redistributed here as extracted clinical constants for calculation use |
| Monthly height reference (附表1) | JSPE 2000 National Survey Attached Table 1 | Verified by monthly continuity tests and under-3 SDS spot checks | Redistributed as tabulated clinical reference values |
| Height velocity reference | Suwa et al. (1992) longitudinal Japanese growth velocity standard | Verified by HV interpolation tests and puberty-peak physiological checks | Redistributed as tabulated clinical reference values |
| Obesity index formulae | JSPE / Japanese Ministry of Health and Welfare pediatric standard weight equations | Verified by obesity-index unit tests over infant and school-age ranges | Formulae only; no separate copyrighted table redistributed |
