# dGC-JP: 日本版デジタル成長曲線 (Digital Growth Chart for Japan)

日本人の成長基準に基づく成長指標の算出および可視化プラットフォームです。

## 概要

本ツールは、小児科医や保健指導に携わる専門家が、日本人児童の成長データを評価・可視化するために開発されました。入力されたデータに基づき、身長・体重のSDS（標準偏差スコア）、肥満度、身長速度（HV）を計算し、公開された日本人小児の成長基準・関連文献に基づく成長曲線上にプロットします。

## 主な機能

- **成長曲線の描画**: 2000年度全国調査に基づき2016年に公表されたLMS成長基準を用いた 0SD, ±2SD, ±2.5SD, ±3.0SD の基準線表示。
- **指標の自動算出と詳細な年齢表示**:
  - **身長SDS**: 日本小児内分泌学会（JSPE）「附表１」の満月齢別平均値・標準偏差（2000年版）を用いて算出。
  - **体重SDS & 成長曲線背景**: 2016年に公表されたLMS成長基準に基づく補間算出。
  - **年齢併記表示**: 小数点4桁表示（例：3.5000歳）と満年齢月齢表記（例：満3歳6ヶ月）を併記。
  - **肥満度（身長別標準体重・年齢別標準体重）**
  - **身長速度 (Height Velocity: HV) および その SDS**（Suwaら, 1992年の縦断的成長基準に準拠）
- **データ入力支援**: Enterキーによる測定入力欄間のフォーカス移動を実装。
- **修正月齢対応**: 早産児（37週未満）の場合、修正月齢でのプロットおよび評価が可能。修正年齢に対しても、同様に小数点4桁と簡潔な満年齢月齢表記を併記。
- **データのエクスポート/インポート**: 入力したデータをJSON形式で保存・読み込み可能。
- **印刷・画像出力**: 成長曲線の高解像度PNG保存および印刷用レイアウト出力。
- **アクセシビリティへの配慮**:
  - **キーボードナビゲーション**: `:focus-visible` と「メインコンテンツにスキップ」リンクを実装。
  - **スクリーンリーダー利用への配慮**: D3.jsグラフに `role="img"`、`aria-label`、`aria-describedby` を付与し、代替データ表示を実装。
  - **セマンティックなリアルタイム警告**: 測定エラー（生年月日逆転、未入力、早産児週数外の警告、体重・身長の負値バリデーションなど）は `role="alert"` および `aria-live="assertive"` によって即座に読み上げられます。
  - **テーブル構造の明確化**: 結果一覧テーブルに `caption`、列ヘッダーに `scope="col"`、さらにデータ更新を画面外に通知する動的な `aria-live="polite"` アナウンス領域を設置。

## 参考文献・出典

本ツールのロジックは以下の臨床基準に基づいています：

- **身長SDS（満月齢基準）**: [日本小児内分泌学会 附表1（平均体重／標準偏差 2000年）](https://jspe.umin.jp/medical/files/fuhyo1.pdf)
- **成長曲線・体重SDS**: Isojima et al., *Clin Pediatr Endocrinol.* 2016;25:71-76. [DOI: 10.1297/cpe.25.71](https://doi.org/10.1297/cpe.25.71)
- **肥満度計算**: *Clin Pediatr Endocrinol.* 2016;25:77-82. [DOI: 10.1297/cpe.25.77](https://doi.org/10.1297/cpe.25.77)
- **身長速度SDS**: Suwa S, Tachibana K. *Acta Paediatrica Japonica.* 1992;34(1):61-68. [DOI: 10.1111/j.1442-200X.1992.tb00931.x](https://doi.org/10.1111/j.1442-200X.1992.tb00931.x)

## プライバシーとセキュリティ

- **ローカル完結型**: 入力された患者IDや測定データはすべてブラウザ内蔵のメモリで処理されます。外部サーバーへ送信・蓄積されることはありません。
- **揮発性**: セキュリティのため、ブラウザをリロード（再読み込み）すると入力データは破棄されます。データの保存が必要な場合は、ツール内の「保存」機能を利用してください。
- **レビュー用アクセス制限**: PasswordGateは助成金審査・レビュー期間中に一般利用を抑制するための簡易アクセス制限です。GitHub Pagesのstatic client-side applicationであるため、本格的なauthentication/security boundaryではありません。現在のソースコードには平文passwordを保存せず、PBKDF2-SHA256で生成したsaltとverifierのみを保持します。ただし、この変更は過去のGit履歴に含まれるcredentialを削除するものではありません。client-side gateは意図的な解析・迂回を完全には防止できず、患者の機密情報を保護するものではありません。

## 開発環境と品質管理

- **フレームワーク**: React 19 (TypeScript)
- **ビルドツール**: Vite
- **可視化**: D3.js (データ可視化)
- **デザイン**: Tailwind CSS, Shadcn UI
- **品質管理 & 臨床データバリデーション**:
  - **計算ロジック検証**: VitestによるLMS、各種SDS、肥満度、満月齢算出などの自動テストを実装。
  - **臨床基準データの整合性検証**: 乳幼児期の変化、思春期の発育ピーク年齢差、17.5歳付近の成長平坦化などを自動整合性テスト・回帰テストで確認。
