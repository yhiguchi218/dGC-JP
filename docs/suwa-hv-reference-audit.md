# Suwa HV基準表 原典照合記録

実施日: 2026-10-15

この文書は、`src/data/suwa-hv-data.ts` の `SUWA_HV_BOYS` / `SUWA_HV_GIRLS` を原典の表と照合した記録です。
照合の対象はSuwa身長速度（HV）表のみです。他の基準データ（身長・体重のLMS、JSPE附表1、肥満度の式）の検証を意味しません。

## 1. 原典

| 項目 | 内容 |
|---|---|
| 論文 | Suwa S, Tachibana K, Maesaka H, Tanaka T, Yokoya S. *Longitudinal Standards for Height and Height Velocity for Japanese Children from Birth to Maturity.* Clin Pediatr Endocrinol. 1992;1(1):5-13. |
| DOI | [10.1297/cpe.1.5](https://doi.org/10.1297/cpe.1.5) |
| 男児 | Table 3、誌面p.10（PDFの6ページ目） |
| 女児 | Table 4、誌面p.11（PDFの7ページ目） |
| 読む列 | `height velocity (cm/yr)` の `mean` と `SD`（単位 cm/年）。隣の `height (cm)` の列は使用しない |
| 年齢 | `yr-mo` を「年 + 月/12」に換算（13-3 = 13.25歳、13-6 = 13.5歳、13-9 = 13.75歳） |
| 欠損 | 原典は「—」。`null` として保持する（0ではない） |

原典PDFはこのリポジトリに含めていません。再配布権についての判断もしていません（`DATA_SOURCES.md` を参照）。

旧実装が記載していたDOI（`10.1111/j.1442-200X.1992.tb00931.x`）は本原典のDOIではなく、別の論文（Pediatrics International 1992;4(1):87-89, "An Infantile Case of Intestinal Myiasis"）に解決されます（2026-10-15にCrossrefで確認）。旧実装の引用（Suwa S, Tachibana K, Acta Paediatrica Japonica 34(1):61-68）は、今回照合した表の出典としては確認できなかったため、出典を上記の原典に統一しました。

## 2. 照合方法

1. 添付された原典PDFのTable 3・4のページ画像を目視で読み、HV列の年齢・mean・SDを `src/data/suwa-hv-source-fixture.ts` に転記した。実装の表をコピーしていない。年齢は原典の `yr-mo` のまま記録している。
2. 自動テスト `src/data/suwa-hv-reference.test.ts` が、実装表とfixtureを全行（男児71行、女児70行）で比較する。年齢・mean・SDに加え、行の欠落・重複・年齢のずれ、欠損の表現（`null`）も検査する。
3. 修正前の実装表（main `daa000b`）とfixtureを機械的に比較し、差異のある行を洗い出した（使い捨てスクリプトで実施し、リポジトリには含めていない）。差異は25行（男児21行、女児4行）だった。
4. 修正後の実装表がfixtureと全行一致すること、および新しい回帰テストが修正前のコードでは失敗することを確認した。
5. 男児の変更値は旧実装表とも突き合わせた。旧表の13.5〜17.0歳の各行は、原典の0.25歳前の行（13-3〜16-9）の値と一致する。13.25歳の旧値（mean 9.8）は原典にない値で、原典の17.25歳の行（mean 0.5 / SD 0.38）は旧表にない。
6. 表の転記とは独立に、原典本文の記述とも突き合わせた。誌面p.10の「HVが1.0 cm/年未満となる年齢は男児16 9/12歳、女児14 9/12歳」は、修正後の表（男児 16-6: 1.0 → 16-9: 0.8、女児 14-6: 1.1 → 14-9: 0.9）と一致する。旧男児表では17.0歳で初めて1.0未満となり、本文と一致していなかった。誌面p.7・p.12の平均PHV（男児13 0/12歳で9.9 cm/年、女児11 0/12歳で8.3 cm/年）も表と一致する。これらは自動テストにも含めた。

### この照合の限界

- fixtureへの転記とその再確認は、同じAIエージェントが行った。**人による独立した二重入力ではない。**
- 画像の読み取りに基づくため、人が原典と突き合わせる確認が必要である（§5）。

## 5. 未確認事項と人による確認のお願い

- Table 3・4のHV列（mean・SD）の全セルについて、`src/data/suwa-hv-source-fixture.ts` と原典p.10・p.11を人が突き合わせる確認は未実施である。
- 旧実装表に同じ値がなく、今回の転記だけが根拠である **男児 17-3（17.25歳）の mean 0.5 / SD 0.38** を優先して確認する。
- 男児の他の変更行（13-3〜17-0）の値は旧実装表の1行後ろの行と一致しており、旧表とも整合している。ただし、これは人による確認の代わりにはならない。
- AIの画像読み取りの範囲では、判読が曖昧なHV列の値はなかった。
- 参考（HV列ではなく、dGC-JPが使用しない `height (cm)` 列）: Table 3の12-9の身長SDの欄に「5.6\」、Table 4の7-3の身長meanの欄に「0.118.5」と印字されているように見える。いずれも本照合の対象外である。
